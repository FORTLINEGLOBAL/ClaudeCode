CLIENT LOGOS
============
Drop client logo image files here (PNG or SVG, transparent background preferred).
Then add/point an entry in the $fortline_clients array in front-page.php:

    array('name' => 'Client Name', 'file' => 'filename.png'),

If 'file' is empty or the file is missing, the client name is shown as a text tile
automatically — so the wall always looks complete.

Recommended: ~240x120px, logo centered, transparent or white background.
