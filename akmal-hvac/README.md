# כל המיזוג — תכנון וביצוע מיזוג מתקדם

אתר תדמית חד-עמודי של **כל המיזוג** (אקמל), עברית ו-RTL מלא. קובץ אחד (`index.html`)
ללא תלויות בנייה — פותחים בדפדפן או מעלים לכל אחסון סטטי
(Netlify / Vercel / GitHub Pages / אחסון רגיל).

## מצב התוכן

כל 11 העבודות הן **עבודות אמיתיות** עם וידאו מהשטח. הטקסט של כל עבודה מתאר
רק את מה שידוע עליה — סוג המערכת והנכס — ואת מה שסוג עבודה כזה כרוך בו בכלל;
אין בו נתונים שהומצאו (מספר יחידות, שטחים וכדומה).

**מה שעוד חסר לפני עלייה לאוויר:** תמונה של אקמל (`media/akmal.jpg`).
הטלפון בעמוד הוא הטלפון האמיתי: `053-334-6759`.

## מדיה

1. **וידאו הרקע ב-Hero** — `media/hero.mp4` (640×360, 10 שניות, H.264).
   ההפרדה נמוכה יחסית לפריסה על כל המסך, ולכן מוחל עליו טשטוש עדין והגדלה קלה
   כדי שייקרא כטקסטורה. אם יש גרסה ב-1920×1080, החליפו את הקובץ והורידו את
   ה-`filter` מהכלל `.hero__media video` ב-CSS.
   אם הקובץ נמחק — מוצג רקע חלופי מעוצב והעמוד לא נשבר.
2. **מדיה לעבודות** — `media/work-01.mp4` עד `media/work-11.mp4` קיימים כולם.
   אפשר להוסיף `media/work-0X.jpg` לכל עבודה כתמונת כרטיס; בלעדיה הכרטיס מציג
   את הוידאו עצמו — מושתק, בלולאה, ומתנגן רק כשהכרטיס על המסך. הקליפ נחשף רק
   אחרי שנטען לו פריים; אם הוא נכשל נשאר ה-placeholder המעוצב, כך שלעולם אין
   ריבוע שחור. עבודה בלי תמונה ובלי וידאו מציגה placeholder עם אייקון וגוון
   לפי סוג העבודה.
3. **תמונה של אקמל** — `media/akmal.jpg` (ריבועית, למשל 720×720). עד שהקובץ
   קיים מוצג במקומה תחליף מעוצב במקטע "על אקמל".

## עריכת תוכן העבודות

כל העבודות מוגדרות במערך `WORKS` בתחתית `index.html`. כל פריט:

```js
{
  cat:'vrf',                 // vrf | home | finish — אפשר כמה, מופרדים ברווח: 'vrf home'
  type:'מזגן VRF',           // התווית שמופיעה על התמונה
  title:'...',
  text:'הסבר על מהות העבודה',
  tags:['...','...'],
  image:null,                // או 'media/work-01.jpg'
  video:'media/work-01.mp4'  // או null אם אין וידאו
}
```

### קטגוריות הסינון

שורת הסינון מציגה רק קטגוריות שיש בהן **לפחות שלוש עבודות**: הכול (11),
מערכות VRF (6), בתים פרטיים ווילות (4), גבס וגמרים (3). קטגוריה חדשה תתווסף
כ-`<button class="chip" data-filter="...">` רק כשיהיו לה מספיק עבודות בפועל,
ואייקון ה-placeholder שלה נוסף למפה `PH`.

## הערות טכניות

- RTL לפי מאפיין `dir="rtl"` ב-`<html>` + CSS Logical Properties בלבד
  (`margin-inline-start`, `padding-inline-end`, `inset-inline-start`, `text-align:start`).
- מספרי טלפון עטופים ב-`<span dir="ltr">` כדי שלא יתהפכו בתוך טקסט עברי.
- לחיצה בכל מקום בכרטיס עבודה פותחת את הלייטבוקס (לא רק על התמונה) — חשוב במובייל.
- גופן Heebo מ-Google Fonts, עם נפילה לגופני מערכת.
- תמיכה ב-`prefers-reduced-motion` (אנימציות ווידאו רקע מכובים).
- ללא framework, ללא build step, ללא cookies.
