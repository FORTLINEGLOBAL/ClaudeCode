# אקמל — תכנון וביצוע מיזוג מתקדם

אתר תדמית חד-עמודי, עברית ו-RTL מלא. קובץ אחד (`index.html`) ללא תלויות בנייה —
פותחים בדפדפן או מעלים לכל אחסון סטטי (Netlify / Vercel / GitHub Pages / אחסון רגיל).

## מבנה העמוד

| מקטע | תיאור |
|---|---|
| Hero | טאגליין וכותרת משנה מרכזיים על רקע וידאו |
| הצעת הערך | תכנון מקצועי, חומרים הטובים בשוק, ללא קיצורי דרך + מה שהתקנה נכונה מונעת |
| עקרונות עבודה | 12 עקרונות בתכנון ובביצוע |
| מבחר עבודות | 8 עבודות עם סוג, תמונה/וידאו והסבר, כולל סינון לפי סוג ולייטבוקס |
| שאלות ותשובות | 12 שאלות נפוצות |
| צור קשר | טלפון, וואטסאפ ואימייל |

## מה צריך להחליף לפני עלייה לאוויר

כל אלה הם ערכי מקום (placeholders):

1. **וידאו הרקע ב-Hero** — הוסיפו `media/hero.mp4` (מומלץ: 10–20 שניות, לולאה, ללא סאונד,
   דחוס עד ~5MB) ואופציונלית `media/hero-poster.jpg`.
   כל עוד הקובץ לא קיים מוצג רקע חלופי מעוצב — העמוד לא נשבר.
2. **מדיה לעבודות** — `media/work-01.jpg` … `media/work-08.jpg`, ואופציונלית
   `media/work-01.mp4` … `media/work-08.mp4`. תמונה חסרה מוחלפת אוטומטית ב-placeholder.
3. **פרטי קשר** — בחלק `#contact` בקובץ `index.html`:
   הטלפון `050-000-0000` (גם ב-`tel:` וגם ב-`wa.me`) והאימייל `info@example.co.il`.

## עריכת תוכן העבודות

כל שמונה העבודות מוגדרות במערך `WORKS` בתחתית `index.html`. כל פריט:

```js
{
  cat:'vrf',                 // vrf | mini | split | design | commercial | repair (לסינון)
  type:'מזגן VRF',           // התווית שמופיעה על התמונה
  title:'...',
  text:'הסבר על מהות העבודה',
  tags:['...','...'],
  image:'media/work-01.jpg',
  video:'media/work-01.mp4'  // או null אם אין וידאו
}
```

## הערות טכניות

- RTL לפי מאפיין `dir="rtl"` ב-`<html>` + CSS Logical Properties בלבד
  (`margin-inline-start`, `padding-inline-end`, `inset-inline-start`, `text-align:start`).
- מספרי טלפון ואימייל עטופים ב-`<span dir="ltr">` כדי שלא יתהפכו בתוך טקסט עברי.
- גופן Heebo מ-Google Fonts, עם נפילה לגופני מערכת.
- תמיכה ב-`prefers-reduced-motion` (אנימציות ווידאו רקע מכובים).
- ללא framework, ללא build step, ללא cookies.
