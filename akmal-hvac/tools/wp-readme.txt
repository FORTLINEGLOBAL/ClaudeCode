תבנית חד-עמודית ל"כל המיזוג" — תכנון וביצוע מיזוג מתקדם. עברית ו-RTL מלא.

== התקנה ==

1. בלוח הבקרה של וורדפרס: מראה ← ערכות עיצוב ← הוספה ← העלאת ערכת עיצוב.
2. בחרו את הקובץ kol-hamizug.zip והתקינו.
3. הפעילו את התבנית. זהו — האתר עולה מוכן, על כל התוכן, הסרטונים והגופנים.

אם ההעלאה נכשלת בגלל גודל הקובץ (הקובץ שוקל כ-15MB בגלל אחד עשר סרטוני
הווידאו, וחלק מהשרתים מגבילים העלאה ל-2MB או ל-8MB), יש שתי דרכים:

  א. להעלות את התיקייה kol-hamizug דרך FTP או "מנהל הקבצים" בפאנל האחסון,
     אל wp-content/themes/, ואז להפעיל את התבנית מלוח הבקרה.
  ב. לבקש מחברת האחסון להעלות את upload_max_filesize ל-32MB.

== מה יש בתבנית ==

* עמוד אחד עם כל המקטעים: הירו, על אקמל, הצעת הערך, מבחר עבודות (11 עבודות
  עם וידאו, סינון לפי סוג ולייטבוקס), עקרונות עבודה, 12 שאלות נפוצות וצור קשר.
* כל המדיה — אחד עשר סרטוני העבודות, סרטון הרקע ותמונת אקמל — נמצאת בתוך
  התבנית עצמה, ב-assets/media/. אין צורך להעלות שום דבר לספריית המדיה.
* גופן Heebo נטען מ-Google Fonts, בדיוק כמו בגרסה הסטטית.
* RTL מלא: dir="rtl" ו-lang="he" כתובים ישירות ב-header.php, כך שהאתר נשאר
  בעברית ומימין לשמאל גם על התקנת וורדפרס שהוגדרה לשפה אחרת.

== שינוי תוכן ==

מספר טלפון: functions.php, בפונקציה khm_phone(). שלושת הפורמטים (תצוגה,
tel: ו-וואטסאפ) יושבים שם יחד, ומספיק לערוך אותם פעם אחת.

עבודות (WORKS): js/site.js, בראש הקובץ. כל פריט הוא סוג, כותרת, טקסט, תגיות
ונתיב וידאו. נתיבי המדיה נפתרים מול assets/media/ אוטומטית.

שאר הטקסטים (שאלות ותשובות, עקרונות, הצעת הערך): front-page.php.

== כותרת העמוד ==

הכותרת כתובה במפורש ב-header.php כדי שהאתר ייראה מיד כמו הגרסה הסטטית.
מי שמעדיף שכותרת האתר מתוך הגדרות ← כללי תנצח: למחוק את שורת ה-title
מ-header.php ולהוסיף add_theme_support( 'title-tag' ) בתוך khm_setup().
