# Signature assets

Drop the Hatul cat logo here as **`logo.png`** (the full cat + "חתול פיננסי"
lockup). When present, `send_email.py` embeds it inline in the HTML signature
(via `cid:hatul-logo`). If it's missing, the signature falls back to the brand
name as text so the rest of the signature still renders.

Recommended: transparent-background PNG, ~240px wide.
